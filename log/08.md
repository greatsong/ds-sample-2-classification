# 8차시 기록 — 로지스틱 회귀와 후보 모델 비교

## 20105 정민재
- 오늘 결정한 것: 먼저 수업에서 배운 로지스틱 회귀로 분류했다. 정확도는 0.844로 기준선 0.450보다 0.394 높았다.
- AI에게 보낸 프롬프트(원문): 학습 데이터로 로지스틱 회귀 모델을 만들어서 능력치 여섯 개로 포지션 묶음을 분류하고, 시험 데이터의 정확도를 기준선 정확도 옆에 보여 줘.
- AI가 준 것 중 고치거나 버린 것과 그 이유: AI가 입력 변수에 overall, value_eur, age를 함께 넣었다. 우리 질문은 "능력치 여섯 개만"이고 그 셋은 포지션과 직접 관계가 없어서 빼고 여섯 개만 남기도록 고쳤다.
- 느낀 점: AI는 열이 있으면 일단 다 넣는 것 같다.

## 20112 최수아
- 오늘 결정한 것: 같은 학습·시험 데이터로 후보 모델 다섯 개를 비교하고 최종 모델로 로지스틱 회귀를 골랐다. 정확도는 k-NN 0.856, 랜덤 포레스트 0.850, 로지스틱 회귀 0.844, XGBoost 0.819, 결정 트리 0.781이었다.
- AI에게 보낸 프롬프트(원문): 같은 학습·시험 데이터로 로지스틱 회귀, 가까운 이웃 다섯 명을 보는 k-NN, 깊이 4짜리 결정 트리, 나무 300그루짜리 랜덤 포레스트, XGBoost를 만들어서 정확도와 포지션별 F1, 재현율을 한 표로 비교해 줘.
- AI가 준 것 중 고치거나 버린 것과 그 이유: AI가 표를 보여 주기 전에 "XGBoost가 가장 좋으니 그걸 쓰자"고 했는데, 실제 표에서는 0.819로 로지스틱 회귀보다 낮아서 받아들이지 않았다. k-NN과 랜덤 포레스트는 더 높았지만 시험 160명 가운데 2명, 1명 차이였다. 계수로 어느 능력치가 어느 포지션을 가르는지 읽을 수 있고 FW 재현율이 0.82로 가장 높은 로지스틱 회귀를 골랐고, 더 높은 모델의 수치도 지우지 않고 README 표에 그대로 남겼다.
- 느낀 점: 점수만 보고 고르면 숫자 좋은 걸 고르는 것밖에 안 될 것 같아서, 고르는 이유를 먼저 말로 정리한 게 도움이 됐다.

## 20124 한지호
- 오늘 결정한 것: 시험 160명 가운데 로지스틱 회귀가 맞힌 선수는 135명, 기준선은 72명이라는 것을 확인했다.
- AI에게 보낸 프롬프트(원문): 정확도 숫자 말고 시험 선수 몇 명 중 몇 명을 맞혔는지도 같이 보여 줘.
- AI가 준 것 중 고치거나 버린 것과 그 이유: 그대로 받아들였다. 대신 AI가 결과 설명에 "모델이 선수의 역할을 이해한다"고 쓴 문장은 과장이라 앱에 넣지 않았다.
- 느낀 점: 명 단위로 보니 63명을 더 맞혔다는 게 확 와닿았다.

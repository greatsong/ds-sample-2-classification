# 데이터 출처

- 파일: `eafc25_players.csv`
- 1차 출처: EA SPORTS FC 25 선수 능력치(EA Sports, 2024-25 시즌)
- 수집 경로: 공개 페이지(sofifa.com)를 정리한 GitHub 저장소 mzafram2001/ea-fc의 `data/dataset_ea_fc_25.csv`(MIT 라이선스), 2026-10-15 접근
- 게임사가 공식 배포한 데이터가 아님. 공식 대회 출품 시에는 데이터 제공처의 이용 약관 확인이 필요함
- 수업용 사본 경로: https://raw.githubusercontent.com/greatsong/modudata/main/data/eafc25_players.csv (modudata, 상위 800명 정리 사본)
- 내용: 축구 게임 EA SPORTS FC 25의 선수 능력치. 종합 능력치(overall) 순으로 정렬된 상위 800명이며, overall은 77~91
- 받은 날짜: 2026-10-15
- 크기: 800행 · 14열 (여섯 능력치와 positions 열에 빈칸 없음)
- 개인 단위 정보: 공개된 프로 선수의 게임 능력치이며, 연락처·주소 같은 사적 정보는 없음

## 열 설명

| 열 | 뜻 | 이 프로젝트에서 |
|---|---|---|
| name | 선수 이름(짧은 표기) | 확인용 |
| long_name | 선수 전체 이름 | 사용 안 함 |
| positions | 게임에 적힌 포지션. 여러 개면 쉼표로 이어 씀(예: "RM,RW") | 첫 번째 포지션으로 레이블을 만듦 |
| club | 소속 구단 | 사용 안 함 |
| overall | 종합 능력치 | 사용 안 함(질문 범위 밖) |
| pace | 속력 | 입력 변수 |
| shooting | 슈팅 | 입력 변수 |
| passing | 패스 | 입력 변수 |
| dribbling | 드리블 | 입력 변수 |
| defending | 수비 | 입력 변수 |
| physic | 피지컬(몸싸움·체력) | 입력 변수 |
| value_eur | 게임 속 몸값(유로) | 사용 안 함 |
| age | 나이 | 사용 안 함 |
| height_cm | 키(cm) | 사용 안 함 |
